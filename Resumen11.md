# Fundamentos Teóricos y Matemática Interna de SVM: Truco del Kernel, RBF Gaussiano y Regresión #
Las Máquinas de Vectores de Soporte (SVM) constituyen una de las herramientas más robustas en el aprendizaje automático para abordar problemas de clasificación y regresión no lineales. Su funcionamiento óptimo radica en la transformación de espacios de características de baja dimensión a espacios de mayor dimensión donde los datos se vuelven linealmente separables. Este proceso se apoya en el denominado truco del kernel, una técnica matemática que permite calcular el producto escalar entre vectores en un espacio de características transformado sin la necesidad de computar explícitamente las coordenadas de los puntos en dicho espacio, reduciendo sustancialmente la complejidad computacional.

Una medida fundamental en este algoritmo es el concepto de similitud, el cual cuantifica la cercanía o afinidad entre dos observaciones dentro del espacio vectorial. Uno de los núcleos más utilizados para modelar esta noción es el kernel de Función de Base Radial (RBF Gaussiano). La matemática interna del RBF gaussiano evalúa la distancia euclidiana al cuadrado entre dos puntos $x$ y $x'$, mapeándolos inductivamente a un espacio de dimensión infinita mediante la fórmula $K(x, x') = \exp(-\gamma \|x - x'\|^2)$. El hiperparámetro $\gamma$ controla el radio de influencia de las observaciones individuales, regulando así el equilibrio entre el ajuste a los datos de entrenamiento y la capacidad de generalización del modelo.

Para adaptar este marco a problemas de regresión (Support Vector Regression - SVR), la formulación matemática cambia su objetivo de encontrar un hiperplano separador a construir un tubo de margen de error $\epsilon$ alrededor de la función estimada. La función de pérdida insensible a $\epsilon$ penaliza únicamente las desviaciones mayores que este umbral. Mediante la optimización del problema dual empleando multiplicadores de Lagrange y variables de holgura ($\xi_i, \xi_i^*$), SVR logra capturar patrones de comportamiento no lineal continuos con una rigurosa solidez matemática y alta eficiencia computacional.
